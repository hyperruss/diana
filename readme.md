# СМЕНА — центр подготовки специалистов ресторанной индустрии

Одностраничный React-сайт центра подготовки по направлениям:

- бармен;
- бариста;
- официант;
- хостес;
- администратор;
- менеджер смены.

## Технологии

- React 19;
- Vite 7;
- Lucide React;
- CSS без UI-фреймворка;
- Node.js HTTP API и встроенный SQLite;
- интернет-эквайринг Т-Банка через серверный API.

## Локальный запуск

Установить зависимости:

```powershell
npm install
```

Запустить режим разработки:

```powershell
npm run dev
```

Для локальной проверки API во втором PowerShell задайте тестовые реквизиты
терминала и запустите сервер:

```powershell
$env:TBANK_TERMINAL_KEY="ВАШ_TERMINAL_KEY"
$env:TBANK_PASSWORD="ПАРОЛЬ_ТЕРМИНАЛА"
$env:PUBLIC_BASE_URL="http://localhost:5173"
npm run dev:server
```

В браузерный код секреты не попадают. Vite перенаправляет `/api` на локальный
сервер на порту 3000.

Открыть адрес, который покажет Vite. Обычно это:

```text
http://localhost:5173
```

## Проверка production-сборки

```powershell
npm run check
npm run preview
```

Собранные файлы появляются в каталоге `dist`.

## Публикация

Один раз сохраните на сервере реквизиты терминала Т-Банка:

```powershell
npm run configure:tbank
```

Команда запросит `TerminalKey`, затем скрыто запросит `Password` терминала.
Логин от кабинета Т-Бизнес для API не используется. Реквизиты передаются по SSH
и сохраняются только на сервере в `/etc/smena-academy.env` с правами `600`.

Для отдельной кнопки рассрочки получите в кабинете Т‑Бизнес значения
`shopId`, `showcaseId`, `promoCode` для каждого срока и отдельный пароль API,
затем выполните:

```powershell
npm run configure:installments
```

Идентификаторы и коды текущего магазина уже заданы в скрипте. Команда скрыто
запросит пароль API, добавит параметры в тот же серверный файл окружения и
перезапустит API. После этого опубликуйте код командой `npm run deploy`.
Параметры `shopId` и `showcaseId` находятся в разделе «Магазины» → нужный
онлайн-магазин → «Интеграция» → «Кредитование», а `promoCode` — в разделе
«Кредиты и рассрочки». Пароль API задаётся в разделе «Магазины» → «Настройки
API» и не совпадает с паролем терминала интернет-эквайринга. Тестовый параметр
`demoFlow` в production не используется.

В настройках этого же магазина включите HTTP-нотификации и укажите статичный
адрес:

```text
https://smena-academy.ru/api/installments/notification
```

Статичный адрес требуется по документации Т‑Банка даже при передаче
индивидуального `webhookURL` в каждой заявке.

Production-сервер и домен уже указаны в `deploy/deploy.ps1`. Для публикации
текущей версии выполните из корня проекта:

```powershell
npm run deploy
```

Команда:

- выполняет тесты платежного API и production-сборку;
- загружает сайт на `91.197.96.7` по SSH-ключу
  `%USERPROFILE%\.ssh\id_ed25519`;
- публикует frontend и Node.js API, настраивает systemd и прокси `/api` в Nginx;
- создаёт уникальный релиз в `/var/www/smena-academy/releases`;
- атомарно переключает `/var/www/smena-academy/current`;
- проверяет Nginx, systemd, `/api/health` и публичный маршрут `/documents`;
- автоматически возвращает предыдущий релиз при ошибке проверки;
- не удаляет старые релизы и базу заказов в `/var/lib/smena-academy`.

Рабочий адрес: `https://smena-academy.ru`.

Платёж считается успешным только после подписанного уведомления Т-Банка со
статусом `CONFIRMED`. До подключения онлайн-кассы параметр `Receipt` намеренно не
отправляется.

В проекте пока используются рабочее название «СМЕНА», демонстрационные тексты
и локально сгенерированное изображение для первого экрана.

## АТОЛ Онлайн API v4

Чеки формируются сервером после подтверждённой оплаты (`CONFIRMED`) и
передаются напрямую в АТОЛ Онлайн по протоколу API v4. Запросы идемпотентны:
для повторной отправки используется тот же `external_id`. До получения
результата фискализации сервер хранит UUID и проверяет статус документа.

Для настройки используйте XML-файл параметров CMS, полученный в личном
кабинете АТОЛ Онлайн:

```powershell
npm run configure:atol
```

Команда запросит путь к XML, ставку НДС и, при необходимости, систему
налогообложения. XML и пароль не копируются в проект. Настройки объединяются с
существующими реквизитами Т-Банка в `/etc/smena-academy.env` с правами `600`.

Оплата программы до начала оказания услуг оформляется как 100%-я предоплата:
`payment_method=full_prepayment`, `payment_object=payment`, безналичная оплата
`payments.type=1`. После фактического оказания услуги потребуется отдельный
закрывающий чек; его нельзя автоматически сформировать без события о передаче
доступа или завершении услуги.

Для рассрочки сайт сначала создаёт собственный заказ, затем создаёт заявку через
API Т‑Банка с `orderNumber` и `webhookURL`. По уведомлению сервер обязательно
перепроверяет заявку методом `Info`. Чек отправляется в АТОЛ только для реальной
заявки с совпавшими номером и суммой, статусом `signed` и `committed=true`.
Если уведомление потеряется, незавершённые заявки дополнительно проверяются
фоновым процессом. В чеке рассрочки кредитная часть передаётся как
`payments.type=3`, способ расчёта — `full_payment`.
