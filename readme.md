# СМЕНА — центр подготовки специалистов ресторанной индустрии

Одностраничный React-сайт центра подготовки по направлениям:

- бармен;
- бариста;
- официант;
- хостес;
- администратор;
- менеджер смены.

## Технологии

- React 19;
- Vite 7;
- Lucide React;
- CSS без UI-фреймворка;
- Node.js HTTP API и встроенный SQLite;
- интернет-эквайринг Т-Банка через серверный API.

## Локальный запуск

Установить зависимости:

```powershell
npm install
```

Запустить режим разработки:

```powershell
npm run dev
```

Для локальной проверки API во втором PowerShell задайте тестовые реквизиты
терминала и запустите сервер:

```powershell
$env:TBANK_TERMINAL_KEY="ВАШ_TERMINAL_KEY"
$env:TBANK_PASSWORD="ПАРОЛЬ_ТЕРМИНАЛА"
$env:PUBLIC_BASE_URL="http://localhost:5173"
npm run dev:server
```

В браузерный код секреты не попадают. Vite перенаправляет `/api` на локальный
сервер на порту 3000.

Открыть адрес, который покажет Vite. Обычно это:

```text
http://localhost:5173
```

## Проверка production-сборки

```powershell
npm run check
npm run preview
```

Собранные файлы появляются в каталоге `dist`.

## Публикация

Один раз сохраните на сервере реквизиты терминала Т-Банка:

```powershell
npm run configure:tbank
```

Команда запросит `TerminalKey`, затем скрыто запросит `Password` терминала.
Логин от кабинета Т-Бизнес для API не используется. Реквизиты передаются по SSH
и сохраняются только на сервере в `/etc/smena-academy.env` с правами `600`.

Production-сервер и домен уже указаны в `deploy/deploy.ps1`. Для публикации
текущей версии выполните из корня проекта:

```powershell
npm run deploy
```

Команда:

- выполняет тесты платежного API и production-сборку;
- загружает сайт на `194.67.103.218` по SSH-ключу
  `%USERPROFILE%\.ssh\id_ed25519`;
- публикует frontend и Node.js API, настраивает systemd и прокси `/api` в Nginx;
- создаёт уникальный релиз в `/var/www/smena-academy/releases`;
- атомарно переключает `/var/www/smena-academy/current`;
- проверяет Nginx, systemd, `/api/health` и публичный маршрут `/documents`;
- автоматически возвращает предыдущий релиз при ошибке проверки;
- не удаляет старые релизы и базу заказов в `/var/lib/smena-academy`.

Рабочий адрес: `https://smena-academy.ru`.

Платёж считается успешным только после подписанного уведомления Т-Банка со
статусом `CONFIRMED`. До подключения онлайн-кассы параметр `Receipt` намеренно не
отправляется.

В проекте пока используются рабочее название «СМЕНА», демонстрационные тексты
и локально сгенерированное изображение для первого экрана.
